# Security policy

## Supported version

During public alpha, only the latest `0.1.x` release receives security fixes.

## Reporting a vulnerability

Do not open a public issue containing exploit details, secrets, private prompts, or user data. Use GitHub's private vulnerability reporting feature for this repository. If that feature is unavailable, contact the maintainer through a private channel they have explicitly published; no private reporting email is designated in this repository.

Include the affected version, impact, reproduction steps using nonsensitive data, and any suggested mitigation. Do not include production credentials.
